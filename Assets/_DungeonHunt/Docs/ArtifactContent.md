# 아티팩트 콘텐츠

> 기획 표(아티팩트.md) + 확정 사항 반영본. 에셋: `Content/Artifacts/` (세트 6, 아티팩트 28, 카탈로그 1)
> 표를 바꾸면 `Scripts/Editor/ArtifactContentBuilder.cs`의 데이터를 고치고 **DungeonHunt > Content > Build Artifact Content** 실행 (같은 에셋에 값만 덮어씀, 참조 유지)
> 이름은 전부 더미.

## 규칙

| 항목 | 규칙 |
|---|---|
| 세트 Tier | 2개 = Tier1, 4개 = Tier2. **Tier2는 Tier1에 더해짐 (합연산)** |
| 같은 효과 여러 개 | 합연산. 단 "교체 직후 피해 x배"만 곱연산 |
| % 표기 | 피해·이동속도·시간·간격·탄창 비율 = 비율 수정값 (+10% → x1.1) / 치명타 확률·치명타 피해·탄 반환 = %p 고정값 (+20% → +0.2) |
| 무기 특화 세트 | 권총·라이플·샷건 세트. **지금은 무기 잠금 없음** (`GameBalance > Artifact > Weapon Specialization Rules` 끔. 켜면 07 §4.14 잠금 + 특화 세트 1개 제한) |
| 라이플 스택 | 상한 없음. 마지막 명중부터 `RifleStackDuration`(기본 3초) 지나거나 **다른 대상을 맞히면 즉시 초기화**. 첫 명중은 보너스 없이 스택 1 |
| 강화탄 | 수동 교체(Q/E)한 무기의 현재 탄창 전체. 재장전을 시작하거나 끝내면 일반탄. HUD 무기 아이콘 주황 외곽선 |
| 도탄(투사체 상쇄) | 권총 탄 1발마다 발사 때 확률로 결정. 적 탄과 부딪히면 둘 다 사라짐 (같은 틱 플레이어 피격보다 먼저) |

## 확인 필요

- 원본 표에서 `UNIV_02`가 초기·재화 양쪽에 있고 `UNIV_03`이 없어서 **초기 = UNIV_03, 재화 = UNIV_02**로 넣음
- 진행 해금 4개의 조건 연결은 표 순서대로 2층 도달 / 3층 도달 / 첫 클리어 / 두 번째 클리어로 임시 지정
- UNIV_01 최대 HP +10은 기본 최대 HP 6 기준으로 큼 (표 그대로 넣음)
