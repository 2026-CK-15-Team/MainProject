# 방 템플릿 제작 가이드

> AI로 작성한 문서임. 틀린 부분 있으면 바로 수정 바람.

자동 던전 생성기가 읽을 수 있게 방 만들 때 지켜야 할 규칙 정리.
생성기는 방 모양을 만들지 않음. 여기서 만든 방을 **고르고 → 배치하고 → 복도로 잇고 → 안 쓰는 문 막는** 것만 함.

---

## 1. 모양

```
 바운딩 사각형 (W × H)
 ┌──────┬══┬──────┐
 │  x   │  │   x  │   ══ : 문(뚫린 구간). 경계선 위의 바닥 타일 구간
 │      │  └──────┤
 ║                ║   x  : 잘라낸 모서리 (비워둠)
 ║                ║
 ├──┐             │
 │x │             │
 └──┴═══┬─────────┘
```

- 방은 **바운딩 사각형 하나 안에** 다 들어가야 함. 장식·그림자 포함 사각형 밖 타일 금지.
- 모서리를 직사각형으로 잘라낸 모양이면 됨. 자르는 크기, 비대칭 자유.
- **각 변은 바운딩 경계에 닿아야 하고, 닿은 구간 안에 문 1개.**

## 2. 문

- 문 = **바운딩 경계선 위에 있는 바닥 타일 연속 구간**. 생성기가 알아서 찾음.
- **한 변에 문은 딱 1개**, 끊기지 않은 한 덩어리여야 함.
- 문 위치는 변 위 어디든 OK (중앙에서 어긋나도 됨).
- 문 양 끝 바로 옆 경계 칸은 **벽 타일**이어야 함.
- **문은 전부 열어둔 상태로** 만들 것. 안 쓰는 문은 생성기가 벽으로 막음.
- 문 폭은 **팀 표준 폭 권장** (표준값은 팀에서 정하기).
  - 폭 다른 두 문이 이어지면 복도는 **좁은 쪽 폭**으로 만들어지고, 넓은 쪽 남는 칸은 막힘.
- 문 안쪽으로 최소 1칸은 바닥이 이어져야 함 (복도에서 들어오자마자 벽이면 안 됨).

### 문 개수랑 방 종류
| 방 종류 | 필요한 문 |
|---|---|
| 전투방 | 4면 다 권장 (연결 자유도 높아야 배치 잘 됨) |
| 특수방 (시작·보물·도박·상점·비밀·계단) | 실제론 1개만 쓰지만 4면 다 열어두면 어느 방향이든 붙일 수 있음 |
| 보스방 | 2개 씀(입구 + 계단). 4면 다 권장 |

문 없는 변도 가능. 대신 그 방향으론 연결 못 해서 선택 폭이 줄어듦.

## 3. 프리팹 구조

```
Room_Combat_01 (Grid + Room 컴포넌트)
 ├─ Floor        (Tilemap)                ← Room에 연결
 ├─ Wall         (Tilemap + Collider)     ← Room에 연결
 ├─ ...          (장식 등 자유)
 ├─ Door_Up      (RoomDoor, Side = Up)    ← 투명 장벽
 ├─ Door_Down    (RoomDoor, Side = Down)
 ├─ Door_Left    (RoomDoor, Side = Left)
 └─ Door_Right   (RoomDoor, Side = Right)
```

- **원점:** 바운딩 사각형 왼쪽 아래 칸을 셀 좌표 **(0, 0)** 에 맞출 것.
- 셀 크기는 모든 방이랑 던전 Grid가 같아야 함 (프로젝트 공통값).
- `Room` 컴포넌트의 **Floor Tilemap / Wall Tilemap** 칸에 두 타일맵 연결.
  - 컴포넌트 처음 붙일 때 이름이 `Floor`, `Wall`인 자식 있으면 자동 연결됨.
  - 생성기는 **Floor엔 타일 있고 Wall엔 타일 없는 경계 칸**을 문으로 봄.
- **문(투명 장벽):** 열린 문마다 `RoomDoor` 오브젝트 하나씩 두고 방향(Side) 지정.
  - `RoomDoor`엔 Collider2D 필요. 이게 장벽이고, 잠그면 켜지고 풀면 꺼짐.
  - 생성기가 안 이어진 방향 `RoomDoor`는 끄고, 이어진 문은 잠금 풀어둠.
  - 전투 중 잠그기 같은 건 방 쪽 로직에서 `SetLocked`로 처리.
- 적 스폰, `RoomEncounter` 같은 방 전용 컴포넌트는 프리팹 안에 자유롭게.

### 안 쓰는 문 막는 방식
문 칸 Floor 타일 지우고, Wall 타일맵에 `FloorConfig`의 **Wall Tile**을 칠함 (경계선 1줄).
복도보다 넓은 문은 복도랑 안 이어진 칸만 같은 방식으로 막힘.
정면 벽처럼 여러 칸 높이 벽 스타일 쓰면 이 방식 바꿔야 할 수도 있음 → 벽 스타일 정해지면 공유 바람.

## 4. 타일·아트 규칙

### 공통
- **1타일 = 1유닛.** 스프라이트 PPU를 타일 픽셀 크기에 맞출 것 (예: 16px 타일이면 PPU 16).
- 모든 방 프리팹의 Grid Cell Size는 `(1, 1, 0)`로 통일.
- 벽 타일은 **RuleTile 권장** (Tilemap Extras 패키지 이미 설치돼 있음).
  - 이웃 타일 보고 모서리·끝 모양을 알아서 골라줘서, 생성기가 벽 칠할 때 방향 신경 안 써도 됨.
  - 방 벽 칠할 때도 **복도랑 같은 벽 RuleTile 에셋**을 쓸 것. 문 막을 때 이 타일이 방 안에 칠해지므로 다르면 티 남.
- 바닥도 무늬 섞고 싶으면 RandomTile이나 RuleTile(랜덤 출력)로 만들면 됨.

### 복도용으로 필요한 리소스
층 설정(`FloorConfig`)에 타일 에셋 2개만 넣으면 됨.
| 항목 | 내용 |
|---|---|
| Corridor Floor Tile | 복도 바닥. 방 바닥이랑 같은 타일이어도 됨 |
| Wall Tile | 복도 벽 + 문 막는 벽. 방 벽이랑 같은 RuleTile 권장 |

복도는 폭이 문 폭이고, 곧게 가다가 한 번 꺾이는(Z자) 모양임. 벽은 복도 바닥 둘레(대각선 포함) 1칸.
RuleTile 규칙은 최소한 **직선, 바깥 모서리, 안쪽 모서리, 끝(방이랑 만나는 곳)** 모양만 있으면 됨.

### 정렬 (Sorting)
- 방의 Floor/Wall 타일맵이랑 복도 타일맵의 Sorting Layer·Order를 같은 규칙으로 맞출 것.
  - 예: 바닥 Order 0, 벽 Order 10

### 콜리전
기존 무기 코드가 벽을 **Tag "Wall"**(투사체)이랑 **Layer "Wall"**(샷건 판정)로 구분함 → 둘 다 맞춰야 함.
| 오브젝트 | 설정 |
|---|---|
| 방 Wall 타일맵 | Tag `Wall`, Layer `Wall`, TilemapCollider2D |
| 복도 벽 타일맵 | 위와 동일 |
| Floor 타일맵 | 콜라이더 없음 |
| RoomDoor (장벽) | Collider2D (Trigger 아님). 총알도 막으려면 Tag·Layer `Wall` |

- 벽 콜라이더는 CompositeCollider2D로 합치는 거 권장 (Rigidbody2D Body Type = Static, TilemapCollider2D Composite Operation = Merge).
  - 타일 경계마다 끼는 현상 줄고 가벼워짐.
- 문 막을 때 런타임에 타일 바꾸는데, TilemapCollider2D는 자동으로 갱신돼서 따로 할 거 없음.

### 벽 스타일 (아직 미정)
지금은 벽 = 두께 1칸 기준. 탑다운 정면 벽(위쪽 벽이 2~3칸 높이) 스타일로 가면
문 막는 방식이랑 복도 벽 모양을 바꿔야 함 → 정해지면 공유 바람.

## 5. 등록

1. 방 프리팹 `Room` 컴포넌트에서 **Template > Type**(방 종류) 지정.
2. 인스펙터 **Bake** 버튼 누르면 크기랑 문 정보 저장됨. **방 수정했으면 다시 누를 것.**
   - 규칙 위반(변에 문 2개, (0,0) 원점 어긋남, RoomDoor 없음·중복 등)은 콘솔 경고로 뜸.
3. 해당 층 `FloorConfig`의 **Room Prefabs**에 프리팹 추가. 층에 나오는 방 종류마다 최소 1개 필요.

## 6. 확인

자세한 건 [DungeonGeneratorUsage.md](DungeonGeneratorUsage.md) 참고.
- `DungeonPreview`로 씬 뷰에서 배치 확인 가능. 방 프리팹 없으면 임시 모양 방으로 그려줌.
- `DungeonBuilder` 우클릭 → `Build Test Floor`로 에디터에서 바로 생성해볼 수 있음.

## 7. 체크리스트

- [ ] 모든 타일이 바운딩 사각형 안에 있음
- [ ] 바운딩 왼쪽 아래가 (0, 0)
- [ ] 각 변 문이 한 덩어리고, 양 끝이 벽
- [ ] 문 전부 열려 있음
- [ ] 문 폭이 팀 표준이랑 같음 (다르면 의도한 건지 확인)
- [ ] 열린 문마다 방향 맞는 RoomDoor 있음
- [ ] Room 컴포넌트에 Floor / Wall 타일맵 연결됨
- [ ] RoomDoor마다 Collider2D 있음
- [ ] 방 종류(Type) 맞게 지정됨
- [ ] Wall 타일맵 Tag·Layer 둘 다 `Wall`, TilemapCollider2D 있음
- [ ] 벽은 복도랑 같은 벽 타일(RuleTile) 사용
- [ ] Bake 경고 없음
